# СТРАТЕГИЯ — анимированный фильм

Фильм в семи актах (3:30) о стратегии создания великого: окружение → эксперименты → сигнал → фокус → топливо → система → великое.
Визуальный сценарий — в [STORYBOARD.md](STORYBOARD.md).

## Смотреть

- Открыть `index.html` в браузере и нажать «Смотреть». Пробел — пауза, ←/→ — 5 с, F — полный экран, M — звук.
- Готовое видео: `strategy.mp4` (1080p, 30 fps, со звуком).

## Как устроено

| Файл | Что делает |
|---|---|
| `js/core.js` | математика, детерминированный шум, спрайты света, типографика, таймлайн актов и субтитры |
| `js/scenes.js` | семь сцен, титры актов, bloom, зерно, шторки 2.39:1, вспышки и тряска камеры |
| `js/audio.js` | саундтрек, синтезированный в Web Audio: орган, «брааам», тиканье, сердцебиение, гонг |
| `js/player.js` | плеер: постер, таймлайн с актами, клавиатура, полный экран; режим покадрового рендера |
| `audio/strategy.mp3` | саундтрек, заранее отрендеренный из `audio.js` |
| `render/render.mjs` | сборка MP4 через headless Chromium + ffmpeg |

Каждый кадр — чистая функция времени, поэтому браузер и рендерер показывают одно и то же.

## Пересобрать

```bash
node film/render/render.mjs --audio film/render-work/audio.wav     # звук (~7 мин)
node film/render/render.mjs --out film/strategy.mp4 --wav film/render-work/audio.wav --workers 3
node film/render/render.mjs --stills 14.4,33,79 --dir stills       # контрольные кадры
```
